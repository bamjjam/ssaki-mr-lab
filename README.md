# 쌓기나무 MR 탐구실

6학년 수학 **쌓기나무** 단원을 위한 Meta Quest 3용 혼합현실(MR) 교육 앱입니다.
책상 위에 가상 쌓기나무를 손으로 쌓으면서, 앞·옆·위에서 본 모양이 어떻게 바뀌는지 실시간으로 확인할 수 있습니다.

**바로 열기:** https://bamjjam.github.io/ssaki-mr-lab/

## 사용 방법

- **Quest 3:** 헤드셋 브라우저에서 위 주소를 열고 **MR로 시작**을 누릅니다.
  - 손가락 핀치 또는 컨트롤러 방아쇠: 쌓기
  - 컨트롤러 그립 버튼 또는 '빼기' 모드: 빼기
  - '옮기기' 버튼: 판을 내 앞으로 다시 놓기
- **PC 미리보기:** 클릭 = 쌓기, 우클릭(또는 Shift+클릭) = 빼기, 드래그 = 돌려보기

## 기능

- 실제 쌓기나무 규칙 적용 (아래가 받쳐지지 않으면 놓을 수 없음)
- 앞·오른쪽 옆·위에서 본 모양을 실시간으로 표시 (위 모양에는 칸별 개수 표시)
- 문제 모드: 주어진 앞·옆·위 모양과 똑같이 쌓기 (5문제)

## 기술

- WebXR + [three.js](https://threejs.org/) (단일 `index.html`, 설치 불필요)
- GitHub Pages로 배포
